# wallfolio

## Commits and Pull Requests

- Use conventional commits
- Commit after every meaningful change
- Never force push on master
- Always work on a seperate branch with prefix like `feat/`, `fix/`, `chore/`, etc.
- PR should document every change carefully and well-structured, don't leave out any detail. But still remain concise, don't add unnecessary filler.
